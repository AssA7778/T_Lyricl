# 🎙 Telegram Live Lyrics Bio

بیوی (Description) پروفایل تلگرامت رو تبدیل می‌کنه به یه «خواننده‌ی زنده»:
متن آهنگ‌های پلی‌لیستت رو خط به خط، دقیقاً روی تایم واقعی آهنگ، توی بیو می‌ذاره.
قسمت‌های بی‌کلام (سولو گیتار/درام/اینترو/اوترو) با ایموجی ساز پر می‌شه (🎸 🥁 🎹 🌙 …).
آخر هر آهنگ بیو **کاملاً پاک می‌شه**، یه مکث کوتاه، و آهنگ بعدی شروع می‌شه. تا ابد لوپ.

## ⚡ نصب روی سرور با یک دستور

روی سرور (Ubuntu/Debian با systemd، کاربر root):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/AssA7778/T_Lyricl/main/install.sh)
```

اسکریپت خودش همه‌چیز رو انجام می‌ده:

1. `python3` و `git` رو نصب می‌کنه
2. کد رو از همین ریپو می‌گیره → `/opt/lyrics-bio`
3. Telethon رو توی یه venv جدا نصب می‌کنه
4. **فقط بار اول:** شماره تلفن + کد تأیید تلگرام رو می‌پرسه (و پسورد 2FA اگه داری)
5. سرویس systemd می‌سازه که ۲۴/۷ اجرا شه و بعد از ری‌بوت سرور هم خودش بالا بیاد

> 🔄 **دوباره اجراش کنی = آپدیت.** پلی‌لیستت (`config.json`)، فایل‌های LRC شخصیت و
> لاگین تلگرامت (فایل سشن) دست‌نخورده می‌مونن. نصب قدیمیِ دستی هم اگه باشه،
> اول ازش بکاپ می‌گیره بعد مهاجرتش می‌ده.

### مدیریت سرویس

| کار | دستور |
|---|---|
| وضعیت | `systemctl status lyrics-bio` |
| لاگ زنده | `journalctl -u lyrics-bio -f` |
| ری‌استارت | `systemctl restart lyrics-bio` |
| توقف | `systemctl stop lyrics-bio` |
| آپدیت به آخرین نسخه | دوباره همون دستور نصب |
| لاگین دوباره تلگرام | همون دستور نصب + کلمه‌ی `login` آخرش |
| حذف کامل | همون دستور نصب + کلمه‌ی `uninstall` آخرش |

### عوض کردن پلی‌لیست (روی سرور)

```bash
nano /opt/lyrics-bio/config.json          # لیست آهنگ‌ها و تنظیمات
nano /opt/lyrics-bio/lyrics/mysong.lrc    # متن سینک‌شده (اختیاری)
systemctl restart lyrics-bio
```

اگه برای آهنگی `lyrics_file` نذاری، خودش از [lrclib.net](https://lrclib.net) متن سینک‌شده پیدا می‌کنه.
فرمت فایل LRC رو توی `lyrics.lrc.example` ببین.

## اجرای دستی روی کامپیوتر خودت (بدون سرور)

```bash
pip install -r requirements.txt
python lyrics_bio.py
```

بار اول شماره + کد تأیید می‌پرسه؛ بعدش فایل سشن ذخیره می‌شه و دیگه نمی‌پرسه.
توقف: `Ctrl+C` (بیو خالی می‌مونه، یا برمی‌گرده — تنظیم `on_exit`).

## تنظیمات (config.json)

| کلید | معنی |
|---|---|
| `api_id` / `api_hash` | مشخصات API تلگرام. پیش‌فرض creds عمومی Telegram Desktop هست و کار می‌کنه؛ اگه تونستی از [my.telegram.org](https://my.telegram.org) مال خودت رو بگیر بهتره. |
| `songs` | لیست آهنگ‌ها به ترتیب پخش؛ `lyrics_file` فایل LRC توی پوشه‌ی `lyrics/` |
| `premium` | اکانتت پرمیومه؟ (محدودیت بیو: 140 حرف به‌جای 70) |
| `prefix` | ایموجی/متن اول هر خط بیو |
| `min_interval_seconds` | حداقل فاصله‌ی دو آپدیت بیو (محدودیت تلگرام — زیر ۳ نبرش) |
| `late_skip_seconds` | اگه خطی بیشتر از این دیر شده باشه، رد می‌شه تا سینک حفظ شه |
| `clear_after_seconds` | چند ثانیه بعد از آخرین خط، بیو پاک شه |
| `gap_between_songs_seconds` | سکوت (بیوی خالی) بین دو آهنگ |
| `on_exit` | موقع خاموش کردن: `empty` = بیو خالی بمونه، `restore` = بیوی قبلی برگرده |

## چرا Cloudflare Workers نه؟

این پروژه یه **یوزربات MTProto** با اتصال دائمی به اکانت تلگرامته که هر ۳٫۵ ثانیه بیو رو آپدیت می‌کنه.
Workers پروسه‌ی دائمی نداره (هر درخواست چند ثانیه زنده‌ست)، کرانش حداقل دقیقه‌ایه، و کتابخونه‌های MTProto
(Telethon/GramJS) روش قابل‌اتکا اجرا نمی‌شن. نتیجه: تایمینگ درهم‌برهم و قطع‌ووصل — دقیقاً چیزی که نمی‌خوای.
جای درستش VPS یا هر ماشین همیشه‌روشنه.

## هشدارها

- آپدیت بیو محدودیت سرعت داره؛ اسکریپت خودش FloodWait رو مدیریت می‌کنه و سینک رو نگه می‌داره.
- یوزربات روی اکانت شخصی از نظر تلگرام توصیه نمی‌شه؛ ریسک محدودیت خیلی کمه ولی صفر نیست.
- بیو برای همه یه متن واحده — با لحظه‌ی پلی کردنِ هر بازدیدکننده سینک نمی‌شه (محدودیت خود تلگرام؛ هیچ ابزاری نمی‌تونه).
- توی تلگرام → **Settings → Devices** دستگاهی که این بات ساخته رو Terminate نکن — سشن می‌پره و باید دوباره لاگین کنی.
- فایل `lyrics_session.session` مثل کلید اکانتته — هیچ‌وقت جایی آپلودش نکن (توی `.gitignore` هست و گیت پوشش نمی‌ده).
