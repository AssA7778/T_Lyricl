# 🎙 tglyrics

**لیریکِ زنده‌ی همون آهنگی که الان داری گوش می‌دی — خط‌به‌خط، سرِ وقت، توی بیوی تلگرامت.**

مرورگرت (یا گوشیت) موقعیتِ دقیقِ پخش رو به سرورت می‌فرسته؛ سرور لیریکِ سینک‌شده رو پیدا می‌کنه، تأخیرِ شبکه و تلگرام رو جبران می‌کنه، و هر خط دقیقاً همون لحظه‌ای که خونده می‌شه می‌شینه توی بیو. پخش که قطع شه، بیوی اصلیِ خودت برمی‌گرده.

```text
00:12.3   ♪
00:14.8   شب که می‌شه دلم می‌گیره
00:18.2   یاد اون روزا که با هم بودیم
00:21.9   ♪
```

---

## ⚡ نصب روی سرور — یک خط

روی سرور (اوبونتو/دبیان، با root):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/AssA7778/T_Lyricl/main/install.sh)
```

اسکریپت همه‌کار رو خودش می‌کنه:

1. پایتون، venv و git رو نصب می‌کنه
2. کد رو می‌ذاره توی `/opt/tglyrics` و کاربر سرویس جدا می‌سازه
3. `config.toml` رو با یه **توکن تصادفی** برای وب‌هوک می‌سازه
4. همون‌جا می‌پرسه سشن تلگرام رو بسازه؟ (فقط `api_id`/`api_hash` از [my.telegram.org](https://my.telegram.org) + شماره و کد تأیید)
5. سرویس systemd رو روشن می‌کنه — ۲۴/۷ و بعد از ری‌بوت هم خودش بالا میاد

**دوباره اجراش کنی = آپدیت.** کانفیگ، دیتابیس و لیریک‌های دستی‌ت دست نمی‌خورن.

| کار | دستور |
|---|---|
| وضعیت سرویس | `systemctl status tglyrics` |
| لاگ زنده | `journalctl -u tglyrics -f` |
| لاگین دوباره تلگرام | `sudo bash /opt/tglyrics/install.sh login` |
| آپدیت | همون دستور نصب |
| حذف کامل | همون دستور نصب + `uninstall` آخرش |

## 🎧 وصل کردن پلیر

| کجا گوش می‌دی؟ | راهش |
|---|---|
| **مرورگر کامپیوتر** (YouTube Music، SoundCloud، Spotify Web، Apple Music، Tidal، Deezer، YouTube) | ⭐ پیشنهادی — یوزراسکریپت (پایین) |
| **گوشی اندروید** | Firefox اندروید + افزونه‌ی Violentmonkey + همون یوزراسکریپت |
| **پلیر دسکتاپ لینوکس** | توی config بذار `kind = "mpris"` و `pip install dbus-next` |
| **اپِ اندرویدی** (آزمایشی) | `agents/termux-agent.sh` با adb |
| **Spotify API** | فقط اگه اپِ ساخته‌شده با اکانت پریمیوم داری — `kind = "spotify"` |

### نصب یوزراسکریپت (۲ دقیقه)

1. افزونه‌ی [Tampermonkey](https://tampermonkey.net) (یا Violentmonkey) رو نصب کن
2. [این لینک رو باز کن](https://raw.githubusercontent.com/AssA7778/T_Lyricl/main/userscript/tglyrics.user.js) → Install
3. منوی افزونه → **⚙️ تنظیم سرور tglyrics**:
   - سرور: `http://آی‌پی‌سرورت:8787`
   - توکن: همونی که اینستالر آخر کار نشونت داد (توی `/opt/tglyrics/config.toml` هم هست)
4. **🔌 تست اتصال** رو بزن، بعد یه آهنگ پخش کن 🎶

## 💬 کنترل از داخل تلگرام

توی **Saved Messages** (چتِ خودت) بنویس — پیامت با جواب جایگزین می‌شه که چت شلوغ نشه:

| بنویس | چی می‌شه |
|---|---|
| `.lrc` | وضعیت: آهنگ، لیریک، نرخ نوشتن، فلاد، تأخیر |
| `.lrc off` | خاموش — بیوی اصلیت برمی‌گرده |
| `.lrc on` | دوباره روشن |
| `.lrc +300` | لیریک ۳۰۰ میلی‌ثانیه جلوتر (برای همین آهنگ ذخیره می‌شه) |
| `.lrc -250` | لیریک عقب‌تر |
| `.lrc 0` | آفستِ این آهنگ صفر |
| `.lrc reload` | کش رو پاک کن، دوباره دنبال لیریک بگرد |
| `.lrc bio سلام!` | متنِ بیو وقتی چیزی پخش نیست |
| `.lrc limit 70` | سقف کاراکتر دستی |
| `.lrc help` | راهنما |

فارسی هم کار می‌کنه: `.لیریک روشن` ، `.ل خاموش`

وضعیت کامل به JSON: `http://سرورت:8787/status`

بدون این‌که به تلگرام دست بزنه، دقیقاً همون چیزی که قراره بره توی بیو رو توی ترمینال «پخش» می‌کنه:

```bash
cd /opt/tglyrics
```

## ⚙️ تنظیمات — `config.toml`

مسیر: `/opt/tglyrics/config.toml` — بعد از هر تغییر: `sudo systemctl restart tglyrics`

### `[telegram]`

| کلید | پیش‌فرض | معنی |
|---|---|---|
| `api_id` / `api_hash` | — | از [my.telegram.org](https://my.telegram.org) → API development tools |
| `session` | — | `login.py` می‌سازدش. ⚠️ کلیدِ کامل اکانتته — به هیچ‌کس نده |
| `bio_limit` | `0` | سقف طول بیو. `0` = خودکار از خود تلگرام (۷۰ عادی / ۱۴۰ پریمیوم) |
| `idle_bio` | `""` | بیوی وقتی چیزی پخش نیست. خالی = بیوی اصلی خودت |
| `control_chat` | `"me"` | کجا به دستورها گوش بده. `"me"` = Saved Messages، خالی = خاموش |
| `control_prefix` | `"."` | پیشوند دستورها |

### `[rate]` — محافظ FLOOD_WAIT

| کلید | پیش‌فرض | معنی |
|---|---|---|
| `min_interval` | `3.5` | حداقل فاصله‌ی دو نوشتن (ثانیه). خودش یاد می‌گیره و تنظیمش می‌کنه |
| `backoff_factor` | `1.6` | بعد از هر فلاد، فاصله ضرب‌در این می‌شه |
| `max_interval_cap` | `60.0` | سقف فاصله |
| `recover_after` | `25` | بعد از این‌تعداد نوشتنِ بی‌مشکل، فاصله آروم برمی‌گرده پایین |
| `recover_factor` | `0.92` | ضریب برگشت |
| `max_writes_per_minute` | `18` | سقفِ سختِ مستقل |
| `hard_floor` | `2.5` | کف مطلق — هیچ‌وقت سریع‌تر از این نمی‌نویسه |
| `state_file` | `data/rate_state.json` | فاصله‌ی یادگرفته‌شده اینجا می‌مونه تا بعد از ری‌استارت از صفر شروع نشه |

### `[lyrics]`

| کلید | پیش‌فرض | معنی |
|---|---|---|
| `local_dir` | `lyrics` | فایل‌های `.lrc` دستی — «Artist - Title.lrc». همیشه بر اینترنت اولویت داره |
| `cache_db` | `data/cache.db` | کش SQLite |
| `global_offset_ms` | `0` | آفست سراسری (میلی‌ثانیه). مثبت = زودتر نشون بده |
| `interlude` / `show_interlude` | `"♪"` / `true` | چی نشون بده وقتی خواننده نمی‌خونه |
| `long_line_mode` | `"chunk"` | خطِ بلندتر از سقف: `chunk` = اسکرولِ سینک‌شده، `truncate` = بریدن با … |
| `min_chunk_ms` | `1300` | هر تیکه حداقل این‌قدر دیده بشه تا نرخ نوشتن منفجر نشه |
| `prefix` | `""` | متن قبل از هر خط (از سقف کم می‌کنه) |
| `fallback_to_track` / `fallback_format` | `true` | اگه لیریک نبود، اسم آهنگ رو نشون بده |

### `[source]`

| کلید | پیش‌فرض | معنی |
|---|---|---|
| `kind` | `"webhook"` | منبع پخش: `webhook` (یوزراسکریپت/ترموکس) / `mpris` / `spotify` |
| `stale_after` | `45` | اگه این‌قدر ثانیه از دستگاه خبری نشد، «قطع» حساب کن |
| `[source.webhook]` `host`/`port`/`token` | `0.0.0.0`/`8787` | ⚠️ توکن رو حتماً عوض کن (اینستالر خودش می‌کنه) |
| `[source.spotify]` | — | `client_id`/`client_secret`/`refresh_token`/`poll_interval` |
| `[source.mpris]` `player` | `""` | خالی = اولین پلیرِ در حال پخش |

### `[log]` — `level` (پیش‌فرض `INFO`) و `file` (`data/tglyrics.log`)

## 🇮🇷 لیریک فارسی — یه تله‌ی مهم

LRCLIB لیریکِ فارسیِ سینک‌شده **داره**، ولی متادیتاش فینگلیشه: جستجوی «محسن یگانه» صفر نتیجه می‌ده، «Mohsen Yeganeh» هشت‌تا. برای همین tglyrics اسم فارسی رو خودکار فینگلیش می‌کنه و چند حالت رو امتحان می‌کنه — ولی **متنِ نمایشی همیشه همون فارسیِ اصله**؛ فینگلیش فقط برای پیدا کردنه.

آهنگی که LRCLIB نداره؟ فایلش رو دستی بذار: `/opt/tglyrics/lyrics/Artist - Title.lrc` — فرمتش توی `lyrics/HOWTO.txt`. فایل دستی همیشه بر اینترنت برنده‌ست.

## 📏 خطِ بلندتر از سقف بیو؟

اکانت عادی ۷۰ کاراکتر بیو داره، پریمیوم ۱۴۰ (سقف واقعی موقع اجرا از خود تلگرام پرسیده می‌شه). خط بلند به‌جای بریده‌شدن، **سینک‌شده اسکرول می‌شه**: تیکه‌ی بعدیِ همون خط سرِ وقتِ خودش میاد. اگه لیریک کلمه‌ای (A2) باشه، مرز تیکه‌ها دقیقاً روی تایم‌استمپ همون کلمه‌ست. بریدن می‌خوای؟ `long_line_mode = "truncate"`.

## ⚠️ ریسک FLOOD_WAIT — صادقانه

لیریک زنده یعنی هر ۳ تا ۸ ثانیه یک نوشتنِ واقعی توی بیو — ده‌ها برابرِ بات‌های «آهنگ فعلی». تلگرام هم هیچ عدد رسمی‌ای برای این محدودیت نداده. پس tglyrics عدد رو **حدس نمی‌زنه، یاد می‌گیره**:

- هر `FLOOD_WAIT` → همون‌قدر که تلگرام گفت صبر + فاصله‌ی نوشتن نمایی زیاد می‌شه
- بعد از یه دوره‌ی آروم، فاصله کم‌کم برمی‌گرده پایین (هرگز زیر `hard_floor`)
- مقدارِ یادگرفته‌شده توی `data/rate_state.json` می‌مونه
- متنِ تکراری **هرگز** فرستاده نمی‌شه
- اگه نوشتن مجاز نباشه، خطِ قدیمی توی صف نمی‌مونه — وقتش که شد از نو حساب می‌شه؛ یعنی بعضی خط‌ها رد می‌شن ولی **هیچ خطی دیر نمایش داده نمی‌شه**

محافظه‌کارتر؟

```toml
[rate]
min_interval = 6.0
max_writes_per_minute = 10
```

## 🚫 چرا مستقیم از اسپاتیفای/ساندکلاد/تلگرام نمی‌خونه؟

- **Spotify Web API** — از فوریه‌ی ۲۰۲۶ صاحبِ اپ باید پریمیوم باشه؛ تازه `progress_ms` هم ۰٫۵ تا ۱٫۵ ثانیه خطای تصادفی داره (باگ شناخته‌شده).
- **SoundCloud** — اصلاً endpoint «الان چی پخش می‌شه» نداره؛ لیریک هم نداره.
- **آهنگ پروفایل تلگرام** — پخشش سمتِ بیننده‌ست؛ هیچ رویدادی به هیچ سروری نمی‌رسه.
- **Last.fm** — می‌گه *چی* پخش می‌شه ولی نمی‌گه *کجاش*؛ برای سینک بی‌فایده‌ست.

نتیجه: عددِ دقیق فقط از خودِ دستگاهِ پخش‌کننده درمیاد — و اتفاقاً دقیق‌تر از همه‌ی APIهاست، چون `currentTime` مرورگر مقدارِ واقعیِ پلیره.

## 🔧 عیب‌یابی

**بیو عوض نمی‌شه**

```bash
journalctl -u tglyrics -f
curl http://localhost:8787/status | python3 -m json.tool
```

- `playback.track` خالیه؟ → یوزراسکریپت به سرور نمی‌رسه؛ «🔌 تست اتصال» رو بزن
- `stale: true`؟ → دستگاه بیشتر از ۴۵ ثانیه‌ست خبری نداده
- پورت بسته‌ست؟ → `sudo ufw allow 8787/tcp` (اینستالر خودش باز می‌کنه)

**آهنگ پیدا شد ولی لیریک نه** → `.lrc reload`، یا با `simulate.py --duration` امتحان کن، یا فایل `.lrc` دستی بذار

**یه‌کم جلو/عقبه** → `.lrc +250` یا `.lrc -250` (سراسری: `global_offset_ms`)

**فلاد می‌گیره** → `min_interval` رو ببر بالا؛ خودش هم یاد می‌گیره — با `.lrc` مقدار فعلی رو ببین

**بعد از کرش بیوی اصلی برنگشت** → دفعه‌ی بعدِ اجرا خودش برمی‌گردونه (بیوی واقعی توی دیتابیسه)

## 🔒 امنیت

- `config.toml` شامل **StringSession** هست = کلیدِ کامل اکانتت. اینستالر `chmod 600` می‌کنه و `.gitignore` نمی‌ذاره کامیت شه. به هیچ‌کس ندش.
- توکن وب‌هوک بدون تصادفی‌بودن یعنی هر کی آی‌پیت رو بدونه می‌تونه بیوت رو عوض کنه — اینستالر خودش توکن تصادفی می‌سازه.
- بهتر از پورتِ باز: Cloudflare Tunnel یا nginx با TLS — یوزراسکریپت با `https://` هم کار می‌کنه.
- هرگز دو پروسه رو روی یک سشن اجرا نکن — شایع‌ترین دلیل باطل‌شدن سشنه.
- توی تلگرام → Settings → Devices، دستگاهِ tglyrics رو Terminate نکن.

## 🧬 تست‌ها و ساختار

```bash
python -m unittest discover -s tests -t .
```

۱۳۹ تست، بدون شبکه، بدون اکانت — از عقب‌نشینیِ محافظ فلاد تا اثباتِ «هرگز متنِ منقضی نوشته نمی‌شود».

```text
tglyrics/
  clock.py            interpolating playback clock
  scheduler.py        write-or-sleep decision (pure, testable)
  ratelimit.py        adaptive FLOOD_WAIT guard (pure, testable)
  render.py           lyrics + moment -> bio-sized text
  telegram_writer.py  the only place that talks to Telegram
  app.py              orchestrator + in-Telegram control
  lyrics/             LRC parser / LRCLIB client / translit / SQLite store
  sources/            webhook / spotify / mpris
userscript/           browser bridge
agents/               android bridge (experimental)
simulate.py           dry-run without Telegram
install.sh            one-line server installer
```
